你这个目标一升级，实际上就已经不是普通 RAG 了，而是一个 **Game State Aware Agent（游戏状态感知 Agent）**。

RAG 负责回答：

> “火箭筒在哪里？”

而实时 Agent 负责：

> “CJ，你现在血量23%，护甲没了，前面还有4个警察，别冲，右边巷子有防弹衣，地图给你标出来。”

这两者结合，才像一个真正的“圣安地列斯智能副驾驶”。

我觉得可以把共享给 Agent 的游戏数据分成 **6大类**。

---

# 1. 玩家实时状态（Player State）⭐最高优先级

这是 Agent 的“眼睛”。

类似：

```json
{
"health":35,
"armor":0,
"money":250,
"wanted_level":3,
"stamina":60,
"fat":10,
"muscle":75,
"respect":40,
"sex_appeal":20
}
```

Agent 可以产生：

### 血量

数据：

```
health < 30%
```

反馈：

> “CJ，你现在状态很危险，只剩三分之一血，附近没有掩体，建议先撤。”

---

### 护甲

数据：

```
armor = 0
```

反馈：

> “你的防弹衣已经没了，下一次枪战最好先补甲。”

---

### 钱

数据：

```
money
```

反馈：

> “你现在有500美元，不建议买武器，可以去医院附近找免费装备。”

---

### 属性

包括：

## 肌肉 Muscle

影响：

* 近战伤害
* 体型

反馈：

> “你的肌肉已经很高，可以减少近战压力。”

---

## 体力 Stamina

影响：

* 游泳
* 跑步时间

反馈：

> “你的耐力不足，长距离追逐容易掉速。”

---

## 肥胖 Fat

反馈：

> “CJ最近吃太多了，建议去健身房。”

---

# 2. 战斗状态 Combat State ⭐⭐⭐⭐⭐

这个非常适合 Agent。

数据：

```
current_weapon
ammo
enemy_count
enemy_distance
enemy_position
damage_taken
```

例如：

```json
{
"weapon":"AK47",
"ammo":12,
"nearby_enemy":6,
"enemy_distance":20
}
```

Agent：

> “AK47只剩12发子弹，附近有6个敌人，建议换武器。”

---

甚至可以做：

## 自动战术建议

比如：

玩家：

正在帮派战争

Agent：

> “左侧有三个敌人，距离15米，建议利用墙角掩护。”

---

# 3. 任务状态 Mission State ⭐⭐⭐⭐⭐

这个是最有意思的。

数据：

```
mission_name
mission_stage
mission_success
mission_failed
objective
timer
```

例如：

任务：

Wrong Side of the Tracks

Agent知道：

```
mission:
Wrong Side of the Tracks

objective:
Follow Train

status:
active
```

实时：

> “别超过火车太远，Big Smoke的射击距离不够。”

---

任务失败：

```
mission_failed=true
```

Agent：

> “任务失败了，不是你的问题，这关主要难点是火车速度和射击角度。”

（老玩家吐槽模式）

---

# 4. 世界环境状态 World State

这个非常重要。

包括：

## 时间

```
time:23:00
```

Agent：

> “现在晚上11点，赌场区域车辆刷新率比较高。”

---

## 天气

```
weather:rain
```

反馈：

> “正在下雨，摩托车操控会下降。”

---

## 地点

坐标：

```
x,y,z
```

转换：

```
Los Santos
Grove Street
```

Agent：

> “你现在就在Grove Street附近。”

---

# 5. 地图辅助 Navigation ⭐⭐⭐⭐⭐

这是你说的：

> 帮忙标点

核心。

Agent需要：

玩家坐标：

```
player_position
```

数据库：

```
weapon_locations
vehicle_locations
mission_locations
safehouse_locations
```

然后：

用户：

> “帮我找最近防弹衣”

流程：

```
玩家位置
 ↓
查询armor数据库
 ↓
计算距离
 ↓
地图标点
 ↓
语音导航
```

反馈：

> “最近的防弹衣在Pershing Square，距离420米，我已经帮你标点。”

---

# 6. NPC和世界关系（高级功能）

这个会让你的 Agent 从工具变成伙伴。

数据：

```
gang_relation
npc_alive
story_progress
territory
```

例如：

玩家：

在Grove Street

Agent：

> “这里是你的地盘，不过Ballass最近活动频繁。”

---

帮派战争：

```
territory_enemy=true
```

Agent：

> “附近发现敌对帮派活动，建议准备AK47。”

---

# 7. 玩家行为历史（Memory）

这个非常适合 Agent。

记录：

```
death_count
favorite_vehicle
favorite_weapon
failed_missions
play_style
```

例如：

玩家：

经常撞车

Agent：

> “你已经连续三次任务因为车辆损毁失败，这次建议换耐久高一点的车。”

---
